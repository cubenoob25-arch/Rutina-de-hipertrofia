Archivos incluidos:

- sw.js: caché offline (v3; fuerza a descargar la nueva versión).
- icon-192.png e icon-512.png: iconos.

NOVEDADES
1. Entrenamiento en vivo: elegí un día, cargá peso y repeticiones serie por serie, marcá las series realizadas, usá el temporizador y guardá la sesión en el historial. La sesión activa se conserva al cerrar o recargar la app.
2. Mapa muscular: muestra series efectivamente registradas durante la semana actual frente al objetivo semanal. Podés tocar una región del mapa o un músculo de la lista para ver el detalle.
3. Temas: Azul marino, Sepia, Claro y Grafito.
4. Temporizador de descanso configurable desde Ajustes.

ACTUALIZAR GITHUB PAGES
1. Hacé una copia de seguridad desde Ajustes > Copias y datos.
2. Extraé este ZIP.
3. En el repositorio GitHub, usá Add file > Upload files.
4. Subí los archivos que están dentro de Tracker_PWA directamente a la raíz del repositorio y confirmá el commit.
5. Abrí la URL de GitHub Pages. El service worker v3 reemplaza la caché anterior. Si la PWA muestra la versión vieja, cerrala completamente y abrila de nuevo; si hace falta, recargá la URL en Chrome.

COMPATIBILIDAD DE DATOS
Se mantiene la misma clave localStorage (rutina_hipertrofia_tracker_v1), para conservar registros, objetivos, ejercicios y variantes anteriores. El backup JSON ahora también incluye tema, preferencia de descanso y una sesión activa si la hubiera.

NOTA
Los datos se guardan localmente en el navegador/dispositivo. Para transferirlos entre dispositivos, exportá e importá un backup.
